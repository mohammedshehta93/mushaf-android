# المصحف — تطبيق أندرويد

مصحف المدينة النبوية (رواية حفص) بخطوط **مجمع الملك فهد لطباعة المصحف الشريف**، يعمل بالكامل بدون إنترنت.

## المميزات
- **صفحات المصحف الـ604 كما في المطبوع** (15 سطرًا)، لكن كنص حقيقي بخط المجمع — ليس صورًا — فيبقى حادًّا على أي شاشة.
- **ملء الشاشة بدون حواف**، والتقليب يمين/يسار كالمصحف الورقي (السحب لليمين = الصفحة التالية).
- **حجم خط الصفحة** (كالمطبوع / كبير / أكبر — الافتراضي «أكبر»): يكبّر الخط داخل الصفحة نفسها بنفس ترتيب السطور وبدون تمرير؛ السطور القليلة التي تطول تُضغط أفقيًا بنسبة صغيرة.
- **وضع «خط كبير»**: يكبّر كلمات الصفحة نفسها ويعيد ترتيبها مع تمرير داخل الصفحة — حل مشكلة صِغَر الخط في تطبيقات الصور.
- **معاني الكلمات الغريبة** («المُيسَّر في غريب القرآن» — مجمع الملك فهد): ملوّنة بلون مختلف، **ضغطة واحدة** تُظهر المعنى.
- **ضغطة مطوّلة** على أي آية: تفسير ابن كثير، معاني كلمات الآية، علامة توقف، نسخ، مشاركة.
- **تفسير ابن كثير** كاملًا: الآيات المفسَّرة معًا تُعرض معًا، حجم خط قابل للتعديل، التالي/السابق.
- **علامات التوقف**: يفتح دائمًا على آخر صفحة قرأتها، + علامات متعددة بشريط أحمر على الصفحة.
- **فهرس سهل**: السور (مع بحث بالاسم أو رقم الصفحة)، الأجزاء، الأحزاب وأرباعها، العلامات.
- **بحث في القرآن بدون تشكيل**.
- شريط سفلي بمؤشّر للانتقال السريع بين الصفحات مع معاينة اسم السورة.
- ألوان: كريمي / أبيض / ليلي (الليلي يقلب لون الخط نفسه، لا صورة معتمة).
- إبقاء الشاشة مضاءة، تقليب بأزرار الصوت، تحديث من داخل التطبيق.
- **الاستماع**: ٦ قرّاء (الحصري، الحصري المعلّم، المنشاوي، عبد الباسط، المعيقلي، الغامدي)، تظليل الآية المتلوّة وتقليب الصفحات تلقائيًا، تشغيل في الخلفية مع إشعار، تنزيل السور للاستماع بدون إنترنت، نطق الكلمة منفردة، وتتبّع الكلمة بالكلمة للقرّاء الذين تتوفر لهم بيانات توقيت (quran-align).
- **وضع الحفظ**: إخفاء كلمات الصفحة وإظهارها كلمةً كلمة أو آيةً آية، تسجيل الأخطاء ومراجعتها، تكرار الآية/المقطع بعدد مرات، وتعليم الصفحات المحفوظة مع تقدّم كل جزء.
- **الختمة والورد**: خطة ختمة بعدد أيام، حساب الورد اليومي، تتبّع تلقائي للصفحات المقروءة، سلسلة أيام القراءة، تذكير يومي، وويدجت «تابع القراءة» و«آية اليوم».
- **مصحف التجويد الملوّن** (تلوين آلي بأشجار قرارات quran-tajweed) مع دليل الألوان.
- **تفاسير إضافية** تُنزَّل عند الطلب: السعدي، الميسّر، الطبري، القرطبي، وإعراب القرآن.
- **جذور الكلمات**: نوع الكلمة ووزنها وجذرها، وكل مواضع الجذر في القرآن.
- **ملاحظات وتظليل** على الآيات، **ونسخ احتياطي** تصديرًا واستيرادًا.
- **صفحتان متجاورتان** عند تدوير الجهاز، وتنبيه آيات السجدة، وعلامات التوقف على شريط التنقّل.
- **تعلّم الفقه بأدلته**: «بلوغ المرام» لابن حجر (١٧٦٧ حديثًا في ١٦ كتابًا) مع درجة كل حديث وتخريج المحقق، درس يومي، تعليم المحفوظ والمفضلة، بحث، واختبارات مولّدة من نص الأحاديث نفسها.
- **أدوات المسلم اليومية** (زر «المزيد»):
  - مواقيت الصلاة بدون إنترنت (١٠ طرق حساب، تعديل بالدقائق، العصر الحنفي) مع الأذان أو صوت أذان تختاره، وعدّاد للصلاة القادمة.
  - اتجاه القبلة بالبوصلة، والمسافة إلى الكعبة.
  - الأذكار من «حصن المسلم» (١٣٥ بابًا) مع عدّاد لكل ذكر وتذكير بأذكار الصباح والمساء.
  - السبحة الإلكترونية، والتقويم الهجري (أم القرى) بالمناسبات والأيام البيض.
  - وضع رمضان: إمساكية، متابعة الصيام والقيام، وختمة رمضان.
  - متابعة الصلوات اليومية وصلوات القضاء، وحاسبة الزكاة، وتذكير الجمعة بسورة الكهف.
  - حديث اليوم (الأربعون النووية ورياض الصالحين)، وأسماء الله الحسنى مع الآيات التي وردت فيها.
- **استمع** (من شاشة «المزيد»): إذاعات القرآن المباشرة من mp3quran.net (تُفحص كل إذاعة وقت البناء ويُستبعد المتوقف)، بودكاست ديني بالبحث في دليل البودكاست العام مع الاشتراك واستكمال الحلقة من حيث توقفت، وابتهالات وأناشيد **بدون موسيقى** (كل بحث مقيّد بذلك) تُفتح على يوتيوب، مع حفظ روابطك المفضلة.
- **طلب العلم**:
  - **الشيوخ والدروس**: الحويني، العدوي، يعقوب، حسان، سمير مصطفى، أمجد سمير، حازم شومان، إياد قنيبي، عثمان الخميس، ابن عثيمين، ابن باز، الألباني، الفوزان، عبد الرزاق البدر — لكل شيخ: سلاسل منظّمة، محاضرات ومواعظ، مقاطع قصيرة (بدون موسيقى)، بودكاست داخل التطبيق، والقناة.
  - **المتون والمنظومات** مرتبة حسب العلم (الآداب، العقيدة، التجويد، الفقه، الحديث، علوم القرآن والسيرة واللغة)، منها تائية الإلبيري وتحفة الأطفال والجزرية والبيقونية والرحبية — استماع بدون موسيقى، شرح، ونص.
  - **تعلّم التجويد**: ١١ درسًا ميسّرًا مع أمثلة حقيقية من المصحف ملوّنة تُستخرج آليًا، واختبارات.
- الشاشة الرئيسية مقسّمة: القرآن الكريم · الصلاة والعبادات · طلب العلم · استمع · التطبيق.
- بدون إعلانات، بدون تسجيل، بدون صلاحيات غير ضرورية.

## نسخة الآيفون (ويب)
تُنشر تلقائيًا على: https://mohammedshehta93.github.io/mushaf-android/ — تُفتح من Safari ثم «مشاركة ← إضافة إلى الشاشة الرئيسية».
الكود في `web/`، ويُبنى بـ `tools/build_web.py` عبر `.github/workflows/web.yml`.

## المصادر
| البيان | المصدر |
|---|---|
| خطوط الصفحات QCF (الإصدار الأول) | مجمع الملك فهد — عبر `mustafa0x/qpc-fonts` |
| تخطيط الأسطر وربط الكلمات | `zonetecde/mushaf-layout` (مع فحص وتصحيح آلي) |
| معاني الكلمات | المُيسَّر في غريب القرآن — مجمع الملك فهد، عبر `spa5k/tafsir_api` |
| التفسير | تفسير ابن كثير، عبر `spa5k/tafsir_api` (من quran.com / QUL) |
| الأجزاء والأحزاب والسجدات | `fawazahmed0/quran-api` |
| التلاوات | everyayah.com (تشغيل/تنزيل داخل التطبيق) |
| تلوين التجويد | أشجار قرارات `cpfair/quran-tajweed` تُشغَّل على نص التطبيق |
| الجذور والصرف | Quranic Arabic Corpus عبر `mustafa0x/quran-morphology` |
| الفقه | بلوغ المرام عبر `AhmedBaset/hadith-json` (sunnah.com) |
| الأذكار | حصن المسلم عبر `osamayy/azkar-db` |
| حديث اليوم | الأربعون النووية ورياض الصالحين عبر `AhmedBaset/hadith-json` |
| أسماء الله الحسنى | `KabDeveloper/99-Names-Of-Allah` (مع مواضعها في القرآن) |
| الإذاعات المباشرة | mp3quran.net API (تشغيل مباشر من المصدر) |
| البودكاست | Apple Podcasts Search API + ملف RSS لكل برنامج (تشغيل من الناشر) |
| المواقيت والقبلة | حساب فلكي داخل التطبيق (خوارزمية PrayTimes) — مختبر في `PrayerCalcTest` |

البيانات لا تُحفظ في المستودع؛ سكربت `tools/prepare_data.py` ينزّلها وقت البناء ويفحصها، و**يُوقف البناء** عند أي خلل
(تسلسل حروف الخط في كل صفحة، عدد الآيات 6236، 15 سطرًا لكل صفحة، رؤوس السور والبسملة).

## البناء (تلقائي على GitHub)
كل دفع إلى `main` يشغّل `.github/workflows/build.yml`:
1. تجهيز البيانات وفحصها ← 2. اختبارات الوحدة ← 3. بناء APK موقّع بمفتاح الإصدار
← 4. **التحقق من بصمة التوقيع** مقابل `signing/release-cert-sha256.txt` ← 5. نشر Release باسم `mushaf-<versionCode>.apk`.

التطبيق يتحقق من الـ Releases مرة يوميًا ويعرض التحديث للتثبيت فوق النسخة الحالية.

### الأسرار المطلوبة (Settings → Secrets and variables → Actions)
- `KEYSTORE_BASE64` — ملف المفتاح بصيغة base64
- `KEYSTORE_PASSWORD` — كلمة مرور المفتاح
- `KEY_ALIAS` — `mushaf`

لا يُستخدم مفتاح debug للإصدار مطلقًا؛ إن غابت الأسرار يفشل البناء.
المستودع يجب أن يكون **عامًا** حتى يعمل التحديث من داخل التطبيق.
